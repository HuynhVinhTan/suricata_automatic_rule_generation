# AI Source Standard - Suricata AI IDS

## 1. Single source of truth

All official ML/DL training, hyperparameter tuning,
calibration, evaluation, inference, and figure generation
must be implemented in src/netids/.

Notebooks are for EDA, interpretation, and visualization
of saved experimental artifacts. They must not contain
independent official training implementations.

Existing notebooks are preserved as historical research.

## 2. Single experiment entrypoint

Target CLI:
python -m netids.experiments.run

This CLI is not implemented yet.

The entrypoint orchestrates reusable modules.
It must not duplicate model implementations.

Stages:
develop -> calibrate -> test -> report

## 3. Dataset isolation

CTU-13, UNSW-NB15, CIC-IDS2017, and lab PCAP
must have separate dataset adapters and contracts.

Do not silently combine incompatible feature schemas.

Each dataset must record feature definitions, labels,
protocol coverage, exclusions, and input SHA256.

## 4. Experimental integrity

Fit preprocessing on training data only.

Tune and select models using development/validation.
Calibrate thresholds without using final test labels.

Freeze the selected model and configuration before test.
Record random seeds and split provenance.

Never overwrite a previous model or experiment artifact.

Previously consumed evaluation cohorts must not be
represented as untouched independent test results.

## 5. Required outputs

For each applicable experiment:
- Configuration and reproducibility manifest
- Dataset and split provenance
- Model artifact and checksum
- Hyperparameter selection table
- Training history for iterative DL models
- Predictions and true labels
- Precision, recall, F1, AP, FPR and confusion matrix
- Figures generated by Python source
- Scientific limitations and error analysis

## 6. Repository responsibilities

src/netids/adapters/      Dataset loading and mapping
src/netids/features/      Feature contracts and splitting
src/netids/models/        ML/DL implementations
src/netids/experiments/   Train, tune, calibrate, test
src/netids/evaluation/    Metrics and plotting
configs/experiments/      Experiment configuration
artifacts/experiments/    Versioned immutable outputs
notebooks/                EDA and read-only presentation
tests/                    Automated validation

## 7. Deployment

FastAPI, Docker and Suricata integration must consume
frozen validated model artifacts.

Deployment code must not retrain models automatically.
Rule proposals require validation and human review.
